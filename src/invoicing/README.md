# Recurra Invoicing Tool

Dedicated module for Recurra Invoicing services, components, pages, types, and utilities.

## Directory Structure

- `components/`: UI components related to invoicing (e.g. `CreateInvoiceDialog`, `InvoicePDFDocument`).
- `pages/`: Invoicing pages (e.g. `DashboardInvoices`).
- `types/`: Type definitions for invoices, templates, items, and currencies.
- `utils/`: Calculation, PDF generation, and formatting helpers.
- `hooks/`: Custom hooks for invoice state and API actions.

## Main Entry Point

Import invoicing features directly from `@/invoicing` or its submodules.
